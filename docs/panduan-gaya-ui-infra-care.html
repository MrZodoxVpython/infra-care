BGaya Khusus Aplikasi & Dashboard

Pola tata letak dan pendekatan desain yang lazim dipakai di aplikasi operasional.

GOV.UK Style / Government Design System

Putih, tipografi tebal, kontras tinggi, tanpa hiasan, fokus aksesibilitas. Paling “resmi” untuk aplikasi pemerintah.

Utility-first / shadcn-style

Netral, border tipis, sedikit shadow, sangat fungsional. Gaya yang banyak dipakai startup saat ini.

Enterprise Design System (IBM Carbon, Ant Design, Atlassian)

Padat data, tabel kuat, konsisten, terasa korporat.

Analytics / Data-viz First

Grafik dan angka sebagai pusat perhatian, seperti terminal Bloomberg.

Map-first / GIS

Peta menjadi kanvas utama dengan panel melayang di atasnya. Relevan untuk pengaduan berbasis lokasi.

Master-detail / Split View

Daftar di kiri, detail di kanan, seperti aplikasi email.

Kanban / Board

Kolom status dan kartu yang bisa digeser. Cocok untuk alur pengaduan.

Wizard / Stepper

Formulir bertahap, satu keputusan per layar. Cocok untuk “Buat Pengaduan”.

Feed / Social Timeline

Riwayat kronologis seperti media sosial.

Chat-first / Conversational UI

Interaksi utama melalui percakapan, misalnya asisten pengaduan.

Gaya yang sudah dipakai saat ini: Modern SaaS Dashboard UI dengan pendekatan design system — kartu lembut, tipografi rapi, warna status semantik, hero bergradasi, dan palet corporate blue. Pendekatan ini sudah selaras dengan poin 1 dan 4 di atas.
Hindari untuk aplikasi ini: Glassmorphism, neumorphism ekstrem, neubrutalism, cyberpunk/neon, dan maximalism. Risikonya keterbacaan rendah, aksesibilitas gagal, serta kesan kurang serius untuk layanan publik.
